# Serenity A 股产业主线量化因子策略

本文档基于对 `/Users/apple/Desktop/量化策略源代码/` 的全量目录扫描、主题归类和核心源码精读，目标是把现有 Serenity 产业链瓶颈方法论扩展为一套可回测、可审计、可接入 trading agent 的量化因子策略。

结论先行：这套策略不应写成纯技术面或纯机器学习选股。产业逻辑和趋势是准入门槛，量化技术面只做确认、排序、降噪和仓位控制。没有产业证据的强技术形态只能进入观察池，不能进入核心组合。

## 2. 策略定位

策略名：`Serenity Mainline Quant Overlay`

目标：

- 在 Serenity 产业链瓶颈候选池中，识别“产业逻辑强、趋势扩散中、市场共识增强、基本面能验证”的 A 股标的。
- 技术面量化不负责发现长期产业方向，只负责判断产业逻辑是否开始被市场验证，以及价格是否明显脱离基本面验证。
- 输出研究候选、模拟组合和回测报告，不输出交易指令。

核心原则：

1. 产业证据优先：P0/P1 证据、产业链位置、瓶颈弹性、客户/订单/产能/价格验证，是进入主池的前置条件。
2. 行业主线优先：先选产业链与行业，再选公司，不做全市场纯价格排序。
3. 技术面辅助：趋势、量能、资金、扩散度只确认市场是否开始验证产业逻辑。
4. 核心资产集中不惩罚：市场对优质公司的抱团和成交集中不视为负面因子；只有基本面证据被削弱、趋势破坏或交易不可执行时才降权。
5. 排雷硬约束：财务风险、审计异常、ST/退市/停牌/流动性不足优先级高于所有 alpha。

## 3. 策略流程

### 3.1 一级：产业主线准入

输入来自现有代码：

- `src/methodology.ts` 的 `scoreCandidate`
- `Candidate.trace.industryLogic`
- `Candidate.trace.structuredEvidence`
- `Candidate.trace.coverageGaps`
- FFD 行业、公告、研报、资金流、新闻信号
- CNINFO P0 公告和年报

定义 `SerenityPriorScore`：

```text
SerenityPriorScore =
  0.30 * 时代主线强度
+ 0.25 * 下一层瓶颈深度
+ 0.20 * 供需-价格-利润弹性
+ 0.15 * 订单/客户/产能/业绩验证窗口
+ 0.10 * 证据质量
- 0.20 * 覆盖缺口惩罚
```

硬性规则：

- 没有匹配到配置内产业主题的股票，不进入主池。
- 没有候选级 P0 或强 P1 证据的股票，最高只能标记为 `watchlist`。
- 只有技术面强、但没有产业链证据的股票，不进入组合回测的核心候选。

### 3.2 二级：行业主线评分

对申万一级/二级行业、同花顺概念、内部 Serenity 主题分别计算主线得分。

```text
IndustryMainlineScore =
  0.35 * SerenityIndustryPrior
+ 0.22 * IndustryTrendIR
+ 0.18 * FundamentalBoom
+ 0.15 * BreadthExpansion
+ 0.10 * MainMoneyConfirmation
+ 0.05 * AnalystOrReportRevision
- 0.10 * EvidenceGapPenalty
```

因子定义：

- `SerenityIndustryPrior`
  - 该行业/概念与 AI 光互联、先进封装、半导体自主可控、数据中心电力、机器人硬件等产业链瓶颈的匹配度。
  - 来源必须能追踪到 P0/P1/P2。

- `IndustryTrendIR`
  - 过去 120/252 日行业市值加权收益减全市场收益，再除以相对收益标准差。
  - 来自 `2024/29` 的趋势度思想。

- `FundamentalBoom`
  - 行业成分股营收增长、净利增长、经营现金流增长、ROE 改善的中位数。
  - 使用中位数，避免单一大票或亏损票扭曲。

- `BreadthExpansion`
  - 行业内过去 5/10/20 日强势股票占比。
  - 强势可定义为：涨幅超过阈值、站上 MA20、相对行业指数创新高、或风险调整收益为正。
  - 来自 `2023/63` 和 `聚宽2025/98` 的行业扩散思想。

- `MainMoneyConfirmation`
  - 行业/概念层级主力净流入、北向持股比例变化、成交额扩散。
  - 只做确认，不做单独买入理由。

说明：行业成交集中、换手提升、beta 抬升不作为负向因子。核心资产时代，资金集中本身可能是主线确认；这些指标只作为报告中的交易结构观察项，不参与 `IndustryMainlineScore` 扣分。

行业分层：

```text
A 档：IndustryMainlineScore >= 70，核心主线
B 档：55-70，观察/轮动主线
C 档：40-55，只有交易热度或景气初现
Reject：< 40 或证据不足
```

### 3.3 三级：个股因子评分

只在 A/B 档行业和已验证的 Serenity 主题内选股。

```text
StockAlphaScore =
  0.30 * SerenityPosterior
+ 0.15 * IndustryMainlineScore
+ 0.15 * FundamentalVerification
+ 0.12 * QualitySafety
+ 0.12 * RelativeTrend
+ 0.08 * VolumePriceConfirmation
+ 0.05 * ValuationDiscipline
+ 0.03 * LiquidityCapacity
- 0.20 * ThunderstormRisk
```

`SerenityPosterior`：

- 直接使用现有 `scoreCandidate` 的后验分，未来可做 0-100 标准化。
- 高分必须同时满足产业趋势、瓶颈深度、供需利润弹性和证据质量。

`FundamentalVerification`：

- 营收同比/环比改善。
- 净利润或扣非净利润改善。
- 经营现金流改善。
- ROE/ROIC/GPOA 改善。
- 毛利率或单价提升能和产业链逻辑对应。

`QualitySafety`：

- ROE/ROA 为正。
- 经营现金流/利润质量为正。
- 毛利资产比、ROIC 或 GPOA 排名靠前。
- 审计意见无明显异常。
- 近三年无重大财务排雷信号。

`RelativeTrend`：

- 个股 60/120 日风险调整动量。
- 个股相对所属行业指数强度。
- 收盘价位于 MA20/MA60 上方，但不能过度偏离。

`VolumePriceConfirmation`：

- 放量上涨日对应行业指数同向上涨。
- 量价配合不出现明显滞涨、流动性断层或无法成交。
- 主力资金净流入与行业扩散一致。

`ValuationDiscipline`：

- 不要求低估值，但要求估值与盈利验证匹配。
- 高估值成长股必须有订单、价格、产能、客户验证，否则降权。

`LiquidityCapacity`：

- 日均成交额、换手、流通市值满足组合容量。
- 默认剔除过小市值、低成交、长期停牌、开盘一字涨跌停。

说明：个股成交集中、机构持仓集中、北向或融资占比提升，不作为拥挤惩罚。若它们和 P0/P1 证据、盈利验证、行业扩散同向，视为市场共识增强；若出现放量滞涨、趋势破坏或无法成交，则归入 `VolumePriceConfirmation` 或 `LiquidityCapacity`，而不是单独设置拥挤降权。

`ThunderstormRisk`：

来自排雷模块，出现以下信号时扣分或剔除：

- 应收账款/收入异常偏高。
- 应收账款、其他应收、存货异常上升。
- 软资产比例异常。
- 现金销售率偏低。
- 自由现金流恶化。
- 毛利率上升但存货周转下降。
- 商誉/净资产、商誉/利润过高。
- 存贷双高。
- 审计意见异常。

## 4. 组合构建

默认组合：

- 持仓数：15-30 只。
- 单票上限：5%。
- 单行业上限：30%-35%。
- 单 Serenity 主题上限：40%。
- 防御质量/红利底仓：0%-40%，由市场风险状态决定。
- 调仓频率：行业月频，个股周频；证据突发可触发临时降权。

市场状态分三档：

```text
RiskOn:
  指数位于 MA60 上方，市场宽度改善，主线行业 A/B 档数量增加。
  股票仓位 80%-95%。

Rebalance:
  主线仍强，但财报真空、增量催化不足或指数风险偏好下降。
  股票仓位 50%-75%，增加红利/公用/银行/现金类 ETF。

RiskOff:
  指数跌破 MA60，行业扩散恶化，或产业证据被反证削弱。
  股票仓位 20%-50%，只保留高证据、高质量、未破趋势的核心候选。
```

止损不是核心 alpha，但必须有组合级风控：

- 个股跌破入选逻辑对应的技术确认线，降权而非机械清仓。
- 行业主线从 A/B 降为 C，行业仓位降半。
- 产业证据被 P0 反证推翻，退出观察。
- 财务排雷触发，直接剔除。
- 成交集中度可作为报告观察项，但不触发仓位降档；仓位调整由趋势、扩散、证据和交易可执行性决定。

## 5. 回测规则

必须处理 A 股交易约束：

- T+1。
- ST、退市整理、停牌、上市未满 120 日剔除。
- 主板、创业板、科创板、北交所涨跌幅限制差异。
- 涨停不可买入，跌停不可卖出。
- 财报、公告、研报、FFD 信号必须按 `observedAt/pubDate` 对齐，禁止未来函数。
- 买入用下一交易日可成交价格，不使用当日收盘后才知道的数据。
- 成交成本：佣金、印花税、滑点。
- 滑点与成交额/换手率/流动性挂钩，不使用 0 滑点。

回测评价：

- 行业层：行业 RankIC、行业多空收益、行业命中率。
- 个股层：RankIC、ICIR、分组收益、换手率、胜率。
- 组合层：年化收益、最大回撤、Calmar、Sharpe、月度胜率。
- 风格归因：size、beta、momentum、residual volatility、growth、earnings yield、liquidity。
- 产业归因：收益来自哪个 Serenity 主题、哪个瓶颈链条、哪个证据层级。
- 稳健性：分年度、分市场状态、参数扰动、样本外测试。

最低合格标准：

```text
RankIC > 0.03
ICIR > 0.5
换手率可解释且交易成本后仍有效
最大回撤显著低于纯主题等权组合
行业/市值中性后仍有正 alpha
样本外不崩溃
```

## 6. 为什么不直接照搬源码里的高收益策略

不照搬小市值/微盘：

- 很多历史收益来自小市值 beta、流动性溢价和阶段性监管环境。
- 容量差，滑点敏感。
- 与“产业链瓶颈研究 agent”的定位不一致。

不照搬打板/集合竞价：

- 强依赖盘中执行、涨停制度和撮合细节。
- 回测容易美化。
- 无法解释产业逻辑，只适合短线交易系统。

不直接上机器学习：

- 源码中多数机器学习策略样本短、特征多、标签弱、调参风险高。
- 先做可解释因子和归因，再考虑机器学习融合。
- 机器学习可用于因子权重审计，而不是直接决定买卖。

不直接做 ETF 轮动：

- ETF 轮动适合防御资产配置，不适合作为 A 股产业链候选发现。
- 可用作 RiskOff 或 Rebalance 状态下的替代资产。

## 8. 最终策略定义

一句话版本：

> 先用 Serenity 方法论确认“时代主线里的下一层瓶颈”，再用行业趋势、扩散度、景气和市场共识判断主线是否处于可交易窗口，最后在主线内部用质量、盈利验证、相对趋势、量价确认和排雷因子排序个股。

可回测规则版本：

1. 每月计算行业/概念 `IndustryMainlineScore`。
2. 只保留 A/B 档行业和 Serenity 高相关主题。
3. 每周在这些行业内计算 `StockAlphaScore`。
4. 剔除 ST、次新、停牌、涨跌停不可交易、财务排雷、证据不足标的。
5. 按分数选 15-30 只，行业和主题限权。
6. 根据市场状态调整总仓位和红利/现金类资产比例。
7. 回测时按下一交易日可成交价格执行，并计入真实成本和涨跌停约束。
8. 输出收益、回撤、IC、行业归因、风格归因、证据归因。

这是适合当前 trading agent 的量化策略形态：它不会让技术面凌驾于产业判断之上，但会让产业判断变得可排序、可回测、可风控。

### 1.3 哪些窄是设计意图（保留），哪些是缺陷（重写）

**设计意图，保留：**
- topN 固定席位。宁缺毋滥、防清单膨胀，符合确定性纪律。128→15 的截断本身不是问题。
- 主题门"先定产业主轴、再映射公司"的架构方向。产业趋势优先是方法论基石。
- 后验证据加成的结构（prior 主导排序 ρ=0.713、posterior 边际修正 +9~+26）——诊断确认它**不是**漏斗变窄的原因，方向和幅度都符合设计意图。
- 拥挤/反身性惩罚（−6/封顶 medium）：幅度小、不进主轴、只压置信度，正是方法论要的形态。

**缺陷，必须重写：**

1. **"没读过材料" 与 "材料读了但不行" 被打成同一个低分。** source-registry 仅 185 条、几乎只覆盖热门光通信/半导体，86% 匹配股因"系统没读过它的材料"被锁死在 44 分上限。墓地分类自己承认二者不同（evidence-gap 1540 条 vs below-entry-bar 74 条），但分数不区分。任何未被 185 条 source 覆盖的真卡点公司**永远不可能入选**——系统性假阴性。
2. **主题关键词 includes 匹配器。** 5 主题 × 8-10 关键词对名称/行业/概念字符串做小写 includes：既漏掉 70.1% 市场（假阴性），又让两个宽主题放进 1416 只噪声（假阳性）。噪声还污染下游——墓地召回（N2）和主题 bandit 校准（cli.ts:886-896）都在这份以宽主题噪声为主的样本上运行，稀释校准信号。
3. **"63.3 入场线"是幸存者伪影。** 它只是 2026-07-02 run 第 15 名拓荆科技的分数（screener.ts:42 slice 截断、cli.ts:544 回写，已核对 reports/screen-2026-07-02T11-47 与墓地 1614 条 detail），今日复跑已漂移到 69.4（07-03 取证复跑口径，该次结果未落盘 reports/）。1614 条墓地记录把它写成语义化的 "entry bar"，复盘者会误当校准过的质量线。
4. **主题关键词自我循环打分。** matchedThemes 的 keywords 被拼进 combinedResearchText（methodology.ts:255-266），其中"材料/设备/连接器"等词同时出现在 NEXT_LAYER_BOTTLENECK_TERMS（184-209）——命中主题即白送 bottleneckDepth 分，与 source 证据无关，夸大了无证据股票的先验区分度。
5. **负面信号惩罚是死配置。** 空头词（"铜互连延寿/价格战"等书面语）对 1655 只匹配股 0 命中、1640 只被埋者 0 命中。METHODOLOGY_NOTE:105 承诺的"对称评分"在数据层面未兑现；当前唯一有效负面通道只剩一票否决词 + ST 名称正则（methodology.ts:453）。
6. **先验四组件失分高度集中于证据依赖项。** supplyDemandProfit 失分 97%（92% 为 0 分）≈ expectationGap 97% > bottleneckDepth 73% > primaryTrend 52%——前两项本质是"关键词在 source 文本中的命中数 ×1.6/×1.4"，没 source 就没分，把证据覆盖问题二次放大进先验。

## 2. 重写方案（按 Serenity 分层架构）

### 2a. 先验层拓宽

**核心思路：主题门保留，但从"唯一入口"变为"三通道并联"；入场线从绝对分改分位数制。**

#### 通道 1：主题门换匹配器（修缺陷，非新增）

- 把字符串 includes 换成**板块成分映射**：东财免费接口可取概念板块成分列表，FFD 有 `ffd_industry_stocks` / `ffd_industry_overview`。主题定义从"关键词清单"变为"概念板块 ID + 申万行业代码清单"，成员关系由交易所/数据商维护，不再自己猜字符串。
- 同步修复自我循环：**主题关键词不得拼入 combinedResearchText**（methodology.ts:255-266），bottleneckDepth 只允许由 source 证据文本触发。

#### 通道 2：基本面拐点通道（不经主题、不经研报覆盖的新入口）

财报数据 5535 只全覆盖、法定披露、证据平权——这是唯一能结构性解决"70.1% 零记录"的确定性通道。

- **口径铁律（华泰3/华泰8/星火12 三方互证）：单季 > TTM > 三年复合（3y 全部无效）；边际变化 > 静态水平。**
- 采用**增量式单季因子**（星火12，Asness 2019 构造）：dROEQ =（本季单季归母净利 − 去年同期单季归母净利）/ 去年同期归母权益；dGPOAQ / dROAQ / dGMARQ 同理。分子用绝对增量、分母沿用基期，规避负基数下同比增速失真。
- **规则形态（计数门槛，不是加权）**：例如"9 个质量子因子（星火12 表10 终选口径：4 盈利 ROEQ/ROAQ/GPOAQ/GMARQ + 4 成长同比 dROEQ 等 + 股息率 TTM；原文安全性三项 Beta/特质波动率/杠杆实证后被舍去、未入合成）中同比改善的**个数 ≥ 6**，且连续 2 个报告期成立 → 进入'基本面拐点'候选池"。计数是布尔条件的叠加，不是分数合成。
- 注意：星火12 原文用 RankICIR 加权合成——**该合成方式违反铁律，明确不采纳**，只移植其子因子定义与"边际改善"结论，改造为计数门槛。改造后的胜率研报未测过，属外推，上线走影子信号。

#### 通道 3：市场反向发现主题（行业趋势 IR 提示）

- 行业超额收益 IR = 行业近 1 年市值加权超额收益 /（行业日收益 − 市场日收益）std（策略源码组）。**IR 排名前列但不在预定义主题内的行业，自动输出"候选产业主轴"提示**——只提示、由人决定是否立主题，不自动进漏斗。
- 辅助信号：业绩预告事件的**行业聚集密度**（同一申万三级行业预增/预盈密度上升 = 景气验证，与研报覆盖无关），可与 IR 提示互验。

#### 入场线：绝对分 → 分位数制（华泰13 ts_rank）

- 实证：ts_rank(EP, **2 季**) 全 A RankIC 6.21%、多空夏普 2.46（华泰13 的 n 以**季度**计，估值类测试窗口 n=2/4/8/12 季，短窗最优、效果随回看期拉长递减）；有效性以估值与盈利能力两类最强，收益质量、营运能力次之，现金流/资本结构/偿债类较差。
- 规则形态：**"单季 ROA 处自身近 6 季分位 ≥ 80% 且 EP 处自身近 8-12 季（2-3 年）分位 ≥ 60%（估值未透支）"** 这类个股自身时序分位数的布尔组合，替代"综合分 ≥ 某绝对值"。注意：EP 用 2-3 年长窗是保守取向，华泰13 实测长窗效果弱于 2 季短窗，窗口参数需在自有数据上重校准。分位数天然消除跨行业/跨市值口径问题，且每只股票和自己的历史比——低覆盖细分龙头不吃亏。
- **topN 截断与"入场线"语义解耦**：topN 保留为席位规则；墓地 detail 字段改名为"当日第 15 名分数（相对席位线，随日漂移）"，明确它不是质量线。复盘禁止引用 63.3/69.4 作阈值。
- 次新股无足够财务历史算不了分位数——设豁免通道（改用上市以来全历史分位 + 标注低置信），防止次新细分龙头被系统性漏掉（华泰13 警示）。

### 2b. 证据后验去绑架

**核心原则：证据从"分值"改为"三态"——有利 / 不利 / 缺失。缺失 = 无信号，绝不 = 低分。**

1. **拆掉 44 分数学锁死。** supplyDemandProfit / expectationGap / sourceQuality 三项在无 source 时不再记 0 分参与排名，而是输出"证据缺失"状态。排名内部只在"证据状态相同"的股票之间可比；高先验 + 证据缺失的股票进**证据补齐队列**（已有机制），并在报告中以独立区块呈现，而非沉底。
2. **公司自披露证据平权通道。** 业绩预告/快报是法定披露（中小创强制），对低覆盖小票覆盖 70%+，与分析师覆盖完全无关——这是"覆盖少 ≠ 分低"的最直接解法。预告区间取均值（偏差中位数 ≈5%）、快报偏差 <2%；一旦发布立即替代分析师预期作为最新盈利估计。仅披露增速区间的预告不倒算净利润（误差均值 27.7%，星火11），跳过等快报。
3. **覆盖密度降级为上下文变量。** 华泰系列9 实证：关注度/覆盖度类因子与市值相关 54-59%、alpha 微弱——覆盖度是市值/指数成员的函数，不是质量信号。expectationGap 评分中移除任何"覆盖多→分高"的通道；唯一保留用法是**反向拥挤观察**（覆盖/买入评级报告数短期暴增 = 拥挤提示，进 overlay 不进分）。
4. **覆盖的一阶导数是事件，存量不是证据。** 首次覆盖、评级上调至买入、金股入选——低覆盖股一旦出现反而是更强事件（见 2d）。
5. **source-registry 扩容。** 185 条几乎只覆盖热门光通信/半导体——瓶颈是覆盖广度不是打分公式。批量接巨潮公告（cninfo connector）+ FFD `ffd_announcements`，让"读过材料"的分母从 233 扩大一个量级。
6. **分析师数据时效硬过滤。** 任何用到分析师预测/评级/目标价的规则必须携带"最近预测日期"字段，**≤90 天**否则视为缺失（星火13 陈旧数据陷阱：低覆盖股受害最重，恰是 Serenity 的重点池）。
7. **墓地死因与排名一致化。** evidence-gap 与 below-entry-bar 在墓地里分类不同、在排名里也必须不同：前者标"待补证据"可复活，后者标"证据否决"按半衰期冷却。

### 2c. 预期差落地（expectationGap 从关键词判断改为可计算定义）

按"数据可得性 × 实证强度"排序的选型：

| 优先 | 因子 | 定义 | 研报出处与实证 | 数据（字段级） | 取不到怎么降级 |
|---|---|---|---|---|---|
| 1 | **ESP 单季净利超预期幅度** | ESP=(单季实际−单季预期)/\|单季预期\|；预期用"当年一致预期净利润 − 已披露累计"分解到季；实际优先用业绩预告（区间均值）/快报，比正式财报提前 20-180 天 | 预期差 A 组：五篇中唯一能用东财免费数据完整落地；布尔事件（ESP>0）可加幅度分档 | 业绩预告/快报/定期报告：东财数据中心接口（免费但项目未接入，现有 eastmoney connector 仅行情快照+K线）+ 已有 cninfo 公告 connector + FFD `ffd_announcements`；当前一致预期：东财 F10 盈利预测页（**逐股页面接口、仅覆盖有分析师覆盖的个股、需新增抓取**，已接入的行情 API 无盈利预测字段）；去年同期单季：财报差分 | 设"预告→快报→正式财报"三级复核，信号随披露层级升级/降级；周期行业预告偏差大，标低置信 |
| 2 | **文本标题超预期事件** | 卖方研报标题含"超预期"字样即事件 | 逐鹿7：文本标题超预期 63 日收益 7.54%（同库核心研究员/分析师调升类 7.2-8.9%），显著优于机械对比一致预期增速的定义（仅 2.5-3.4%）；8 类超预期信号中占比最高（29%）。原文事件库为朝阳永续（付费），本方案以 FFD 研报标题正则自建平替 | FFD `ffd_research_search` 标题流，**一条正则即可**，零成本 | 无降级需求（数据原生可得） |

| 5 | **一致预期修正 P1 四阶段** | 月频：均值上调且离散度上升 = P1（少数分析师领先上调） | 华泰系列：P1 组合年化超额 12-19%，三指标（EPS_FY1/FY2/净利FY1）同向**交集**达 29%、回撤 −9.6%——交集是布尔规则不是加权 | **需历史一致预期序列，东财只有当前快照** | **从今天起滚动存档快照**（P0 启动），积累 6-12 个月后以影子信号运行；覆盖 <4 家机构 = 缺失态而非低分 |

**明确不选**：目标价上调事件（原作者系列7已放弃、增强版回撤 −31%，目标价受锚定行为污染）；机械对比"财报增速 vs 一致预期增速"做超预期判定（逐鹿7 证明效果差，不许走捷径）。

**共同警示**：五篇样本集中 2009-2021（含小票壳价值牛市），"年化超额 20-30%"不可视为当下可复现收益，只采信相对排序与规则方向；东财无历史一致预期，Serenity 无法复现回测，上线初期这组因子一律影子信号/观察仓运行。

**对现有 catalysts 机制的两个结构改良（直接对接记忆中"校准无兑现回路"缺口）：**

1. **每个催化剂挂确定性兑现窗口**：业绩类 60-120 交易日、预期修正类 2 个月、情绪动量类 1 个月（中信5 半衰期实测）。超期未兑现 → 自动降权一档；超两个窗口 → 移入墓地并记录"催化剂未兑现"死因，形成兑现回路。
2. **雷区月证据升级**：1 月（年报预告强制披露期）与 4 月（年报+一季报集中期），持仓若无业绩预告/快报确认则降为观察仓、有预增确认则维持——不学聚宽社区整月空仓，只提高证据门槛（纯规则，零数据成本）。

### 2e. 资金情绪辅助层（观察 overlay，不进分，对接连板梯队页）

**选定 3 个指标（负面 1 + 正面 1 + 拥挤对象 1），全部为展示标签，不参与任何排序：**

| 指标 | 定义 | 实证 | 数据 | 标签形态 |
|---|---|---|---|---|
| **bias_turn 换手率乖离**（负面/拥挤） | 近 3-5 日日均换手 / 自身近 2 年日均换手 − 1 | 华泰13/资金 C 组：负向单调性 0.92，最干净零成本的拥挤度代理；乖离口径规避高换手小盘偏差 | 东财日频换手率，零新增成本 | "拥挤警示：当前热度是平时 X 倍"，分位 >80% 亮红 |

**硬约束三条（防重复计数与反向陷阱）：**
- 主力净流入与换手率信息大幅重叠（对换手取残差后多空腰斩，华泰7）——**正面确认与拥挤警示不得对同一信息双向计数**，同一股票两标签同亮时以拥挤警示为准展示。
- **"当日主力净流入为正"是反向/无效指标**（华泰7 明确判定）——盘后简报若引用当日资金流，一律降级为描述性信息，只有 5 日累积或开盘时段口径可作标签。

### 2f. 因子卫生（对现有机制的改良点）

1. **证据时效半衰期标签**（中信5 实测：成长/财报类 4 个月、分析师预期修正类 2 个月、动量类 1 个月、估值类 3 个月）：每条证据入库时挂类型化时效标签，过一个半衰期效力减半（置信度降档，不是分数打折），过两个半衰期归档。参考值作初值，定期用自有信号历史复核（风格切换期会漂移）。注意：中信5 最终的"动态 IC 半衰期加权组合"是综合评分，**整体拒绝**，只取半衰期度量。
2. **历史分位数制**已入 2a；财务信号更新节奏锚定财报披露（4/30、8/31、10/31 三次全量体检 + 新披露事件触发增量），不与量价拥挤赛道竞争（华泰8）。
3. **负面信号通道重建**（修复 0 命中死配置）：空头词从书面语关键词改为**事件源**——①预判 ST 规则（连续三年 min(净利,扣非)<0 进风险名单，预告预增/扭亏移出；交易所规则量化，零参数）②审计意见剔除（近 3 年保留/无法表示/否定意见一票否决）③重要股东减持公告（FFD `ffd_announcements`）④"前期涨幅高 + SUE 最低（业绩不达预期）"负面剔除（星火 SUE×前期涨幅双重独立分组的空头端）。预判 ST 前置于**持仓检查**而非仅建仓时执行——否则重演"该卖的没预警"。
4. **特质动量 IMOM 简化版**（星火5）作"独立行情确认器"证据项：个股月收益对中证全指 + 行业指数二因子回归的残差动量为正 = 市场对其细分龙头地位的投票，完全不依赖研报覆盖。**前提警示**：原文有效性依赖对换手率/市值正交，简化实现有复现失败风险，上线前必须自行验证，且动量类只作确认不单独触发。
5. **相关性去重与剪枝规则**（逐鹿15）：信号清单中 A±B（B 量级远小于 A）式伪复合信号退化为主项；两两高相关的证据规则只保留历史有效性高者——防假多样性。
6. **墓地审计补全**：主题门 0 命中的 3880 只目前零记录，假阴性无法审计——至少按日存"未匹配统计快照"（数量、行业分布、其中基本面拐点通道命中数），让通道 2/3 的召回效果可度量。
7. **单位/口径核对铁律**：任何从研报/聚宽迁移的阈值必须逐字段核对单位（聚宽 roa>0.15 实为 >0.15% 的失效过滤是前车之鉴）；单季度化靠累计值差分，会计追溯调整会产生脏数据（负营业成本/权益跳变），需异常值清洗规则；所有单季指标按**实际披露日**对齐，防前视偏差。
